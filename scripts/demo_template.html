01 / Run locally
Your files stay with you.
The browser explorer shows bundled samples only. To validate your own CSV, clone the repository and run the Python command on your computer.
git clone https://github.com/muhammadaliraza126/DataGuard.git
cd DataGuard
python -m venv .venv
# Activate your environment, then:
python -m pip install .
dataguard examples/current.csv \
  --contract examples/contract.json \
  --baseline examples/baseline.csv \
  --output-dir reports/demo

02 / Understand the result
Small examples. Clear behavior.
The passing sample has four records. Its average amount is 35, compared with 25 in the baseline. The failing sample deliberately introduces duplicate IDs, a negative amount, a non-finite number and an unsupported category.
A successful run writes HTML and JSON reports. Exit code 0 means the contract passed, 1 means it failed, and 2 means an input or configuration error.
Try the failing example by replacing examples/current.csv with examples/invalid.csv and choosing a new output directory.


Scope and limitations
DataGuard loads records into memory and uses floating-point numeric parsing. It is intended for modest CSV datasets, not distributed processing or exact financial arithmetic. Reports contain aggregate values and column names. This demo has no file-upload feature. AI assistance was used in development; synthetic results are not evidence of production adoption.
