# Changelog

## 0.1.0 — Initial preview

- CSV contracts for required values, uniqueness, numeric types, bounds and allowed values.
- Structural validation, aggregate profiles and descriptive baseline comparisons.
- Local HTML/JSON output and documented CLI exit codes.
- Installable Python project with a `dataguard` command and `--version`.
- Reproducible sample explorer for passing and failing synthetic inputs.
- Automated tests and GitHub Actions verification.

This is an early preview. Reports are descriptive, and the project is not a production-certified monitoring platform. This changelog does not by itself indicate a published GitHub Release or a PyPI package.
